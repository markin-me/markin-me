
ОБЩИЕ КОМАНДЫ (подходят ВСЕГДА)
| Команда                | Что делает                  | Результат                |
| ---------------------- | --------------------------- | ------------------------ |
| `git pull`             | Забрать обновления с GitHub | `Already up to date`     |
| `git add .`            | Подготовить изменения       | Без вывода               |
| `git commit -m "msg"`  | Создать коммит              | `[main hash]`            |
| `git push`             | Отправить изменения         | Успешный push            |
| `git status`           | Проверить состояние         | Чисто / список изменений |
| `git log --oneline -5` | Последние коммиты           | Список коммитов          |


Создать НОВЫЙ проект с нуля и загрузить на GitHub
| Команда                                                     | Что делает           | Ожидаемый результат                |
| ----------------------------------------------------------- | -------------------- | ---------------------------------- |
| `mkdir new-project`                                         | Создать папку        | Папка создана                      |
| `cd new-project`                                            | Зайти в неё          | Путь к new-project                 |
| `git init`                                                  | Инициализировать git | `Initialized empty Git repository` |
| `git branch -M main`                                        | Назвать ветку main   | Без ошибок                         |
| `git remote add origin https://github.com/USER/NEWREPO.git` | Привязать GitHub     | Команда без вывода                 |
| `git status`                                                | Проверка             | `No commits yet`                   |
| `git add .`                                                 | Добавить файлы       | Команда без вывода                 |
| `git commit -m "init"`                                      | Первый коммит        | `[main …] init`                    |
| `git push -u origin main`                                   | Загрузить на GitHub  | Успешный push                      |



Сменить GitHub-репозиторий для ЭТОГО ЖЕ проекта
| Команда                                                         | Что делает                            | Ожидаемый результат            |
| --------------------------------------------------------------- | ------------------------------------- | ------------------------------ |
| `pwd`                                                           | Проверка текущей папки                | Путь к проекту (`…/markin-me`) |
| `git status`                                                    | Проверка, что это git-проект          | `On branch main`               |
| `git remote -v`                                                 | Показать текущий GitHub-репозиторий   | URL старого репо               |
| `git remote set-url origin https://github.com/USER/NEWREPO.git` | Сменить репозиторий для этого проекта | Команда без ошибок             |
| `git remote -v`                                                 | Проверка, что URL сменился            | Видишь новый репозиторий       |
| `git branch`                                                    | Проверка ветки                        | `* main`                       |
| `git push -u origin main`                                       | Загрузить проект в новый репозиторий  | Отправка файлов без ошибок     |
| `git status`                                                    | Проверка состояния                    | `working tree clean`           |
